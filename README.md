Dissertation 
Title:PHISHSPOTTER
supervisor: Vivian Hocking
vision: For everyday email users and small organisations
Whose problem is that phishing emails trick people into giving away passwords and money, and are hard to spot by eye
The PhishSpotter
Is a web-based phishing email detector
That checks several warning signs in an email (sender, links, wording, attachments) and gives it a risk score. It compares a simple rule-based method against a machine learning method, using public datasets, to find which catches more phishing with fewer false alarms.
